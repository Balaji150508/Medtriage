# MedTriage 

> **A Glass Box AI Decision-Support Engine for Emergency Hospital Triage**  
> *Built for Track 01: MeTTa Foundation (The Glass Box Agent)*

MedTriage uses MeTTa symbolic reasoning to eliminate LLM hallucinations in emergency healthcare. By evaluating patient severity and hospital inventory as hard deterministic facts within AtomSpace, MedTriage provides 100% auditable bed allocations and real-time failure recovery when resources break down.
